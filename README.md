# Snake official website

A lightweight, responsive static website for Snake v1.1.0, an independent programming language by Govind Evern.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. There are no build steps or dependencies.

## Pages

- `index.html` — overview, code showcase, features, examples, and project links
- `docs.html` — language documentation based on the v1.1.0 source and documentation
- `downloads.html` — official Windows x64 release downloads and checksum links
- `404.html` — custom not-found page

The release links point to assets published on [the official v1.1.0 release](https://github.com/govindevern/snake/releases/tag/v1.1.0). Snake source is available at [github.com/govindevern/snake](https://github.com/govindevern/snake).
