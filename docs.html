Learn Snake.

Start writing programs with Snake’s own interpreter, language syntax, and standard library.

Introduction

Snake is an independent general-purpose programming language with a hand-written lexer, recursive-descent parser, Snake-specific abstract syntax tree, and tree-walking interpreter. Source programs run in Snake’s runtime; they are not translated into Python.

The prebuilt standalone distribution targets Windows 10 and 11 on x64. It includes the runtime, so end users do not need Python.

Installation

Download the Windows installer or portable archive from the downloads page. The release is unsigned, so Windows may display a SmartScreen or endpoint protection warning.

After installing, open a new terminal and check the version:

snake --version
snake --help

Getting Started

Save this as hello.snake:

let name = input("What is your name? ")
show "Hello, ${name}!"

Check syntax, then run it from a terminal:

snake check hello.snake
snake run hello.snake

Syntax

Newlines separate statements; semicolons can also separate them. Use # for comments. Strings can use single or double quotes. Snake supports escapes such as \n and variable interpolation using ${name} inside a string.

# A comment
show 'Hello, Snake!'
show "A line\nwith a break"

Variables & data types

let declares an assignable variable. fixed declares a constant. Assignment updates an existing name; it does not create one.

let count = 3
count = count + 1
fixed greeting = "Hi"
show greeting

Values include integers, floating-point numbers, strings, booleans, nil, lists, functions, and standard-library modules. Lists use square brackets and zero-based indexing. Values are not implicitly converted; use str, int, and num for explicit conversions.

let items = ["red", 2, true]
show items[0]
show str(items[1])

Operators

Arithmetic: + - * / %. Comparisons: == != < <= > >=. Logic: and or not. Unary negation and not bind most tightly; calls, indexing, and module members bind tighter. Parentheses group expressions.

+ combines two numbers, strings, or lists. Arithmetic other than + requires numbers. Logic short-circuits and returns booleans. Comparisons support two numbers or two strings.

Conditions & loops

Branches use if … then and end. else is optional. while … do repeats while its condition is true-like. for iterates over a list, string, or range. Use break and continue for loop control.

let total = 0
for n in range(1, 6) do
    total = total + n
end
if total > 10 then
    show total
end

Only false and nil are false-like.

Functions

Functions are implemented in v1.1.0. Declare one with to, parameters in parentheses, and a do … end body. give returns a value; reaching the end without give returns nil. Functions have lexical closures and support recursion.

to square(n) do
    give n * n
end
show square(9)

Error handling

The lexer, parser, and runtime report errors with a source path, line, and column. Error categories include lexical, syntax, name-resolution, type, invocation, and runtime errors. The CLI writes errors to standard error and returns exit code 1. Snake does not silently turn runtime errors into nil.

Programs have a default limit of 100,000 interpreter steps. Pass --limit 0 to disable it. Recursive calls are limited to 256 frames.

Examples

Hello World

show "Hello, Snake!"

Conditions

let score = 72
if score >= 60 then
    show "passed"
else
    show "try again"
end

Loops

let i = 1
while i <= 3 do
    show i
    i = i + 1
end

More runnable files are in the examples folder on GitHub.

CLI reference

snake --version
snake --help
snake run <file.snake> [--limit <steps>] [--debug]
snake check <file.snake>
snake repl

check parses a source file without executing it. run executes a file. repl starts an interactive interpreter; enter :quit or :exit to leave. The standard library includes core conversions, input/output, ranges, and the math, text, list, io, files, and system modules.
